# AI-native Robotics Textbook Constitution

## Core Principles

### Deterministic and Testable Outputs
All outputs must be deterministic, structured, and testable; Requirements → Tasks → Implementations must always align; No hallucinations or unstated assumptions allowed.

### Academic Clarity and Professional Design
Maintain academic clarity and professional textbook design; Follow modular multi-agent architecture; Ensure all components satisfy hackathon scoring requirements.

### Accurate RAG with Citations
RAG answers must be accurate with proper citations; Must avoid cutting sentences during chunking; Preserve meaning and formatting in all transformations.

### Comprehensive Feature Coverage
Include all hackathon bonus features: Subagents, Personalization, Urdu translation, BetterAuth, RAG chatbot, Quizzes & summaries, Dashboard; All components must be fully functional.

### No Hallucinations and Phase Separation
No hallucinations or mixing of phases; Frontend must use Docusaurus and support Urdu RTL; Backend must use FastAPI + Gemini 2.5 Flash + Qdrant Cloud.

### Narrow Agent Responsibility
Each agent must have narrow, well-defined responsibility; Follow clean architecture and avoid unused files; Maintain semantic meaning in translations.

## Technical Constraints and Quality Standards
Frontend must use Docusaurus and support Urdu RTL; Backend must use FastAPI + Gemini 2.5 Flash + Qdrant Cloud; Translation must maintain tone and semantic meaning; Personalization based on user metadata; Each agent has narrow responsibility.

## Development Workflow and Acceptance Criteria
Specifications must define user stories, edge cases, and success criteria; Plans must include diagrams, agent boundaries, and data flow; Tasks must output files or behaviors with ≤ 200 tasks; All hackathon requirements and bonus features must be included; Clean repo structure with working deployment; Demo video < 90 seconds.

## Governance
Constitution supersedes all other practices; All implementations must follow clean architecture; Requirements → Tasks → Implementations alignment must be maintained; All hackathon requirements and bonus features must be included; Compliance with quality standards mandatory.
